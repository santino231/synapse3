Comandos

ANTIRAID

Contamos con sistema de AntiRaid, el cual establece límites para las acciones en tu servidor. Esto hará que los usuarios y bots maliciosos no destruyan tu servidor.

/antiraid limits /antiraid functions /whitelist /set logs /set language /config verify

MODERACIÓN

Comandos de moderación esenciales para sancionar usuarios y mantener el orden del servidor.

/ban /kick /mute /unmute

UTILIDADES

Herramientas de diagnóstico y limpieza para mantener tu servidor optimizado y libre de errores de configuración.

/check roles /check config /clear /nuke

INFO/SOPORTE

Comandos diseñados para ayudarte a configurar el bot, revisar información y resolver errores rápidamente.

/help /info /profile /support
